## 4. 다음 웨이브를 띄울 때

- 워커 기동·권한·회수 정본은 `prompts/orca_workers.md`다. cmd 워커는 반드시 `--yolo`로 띄우고 화면의 `# models:`와 `permission bypass on`을 확인한 뒤 `worker-start --task <id> --terminal <handle> --worktree current`로 붙인다.
- 같은 모델을 두 대 띄워도 된다(이번 세션에 DeepSeek v4.1 Flash 2대를 병렬로 씀). 제출 docx를 고치는 워커는 한 웨이브에 한 명이다.
- 초안 형식: 항목마다 「위치 / 지우는 원문 / 넣는 내용 / 숫자 근거 / 분량」. 지우는 원문은 기준 본문에서 글자 그대로 인용.
- 초안 점검: `BASE_TXT=<기준 본문.txt> python3 -I scripts/docx/check_draft.py <초안.md> [추가 근거 파일]`. 「지우는 원문 불일치」에는 설명문 줄도 잡히므로 눈으로 거른다.
- docx 텍스트 추출: `python3 -I scripts/docx/docx_to_text.py <docx> <txt>`.
- 쪽 수: `/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf <docx> --outdir <임시폴더>` 후 PDF의 `/Type /Page` 수. 한글이 비므로 쪽 수 비교 용도로만 쓴다.
- Command Code가 `Authentication failed`(401)를 내면 `cmd status`가 인증됨이어도 키가 만료된 것이다. 사용자가 `! cmd logout` 후 `! cmd login`을 해야 한다.
- 감시 스크립트는 세션 임시 폴더에 있어 남지 않는다. 다시 만들 때 확인할 것: 보호 파일(v17·v18·기존 백업·양식_원본·규칙 파일) 해시, `git -c core.quotepath=false status --porcelain -uall`로 허용 범위 밖 변경(한글 경로는 quotepath를 꺼야 걸러진다), 워커 화면의 위험 셸 명령(커밋·푸시·삭제·`refac_bid_box/`), 승인 창·인증 오류.

## 5. 주의할 사실 (이번 세션에서 확인)

- 「파일럿 10사」는 v17 일정표 4개월차의 원문이다(6개월차는 「파일럿 20사(가설), 그중 비수도권 10사 이상」). 오기가 아니다.
- 경쟁 비교 표에서 경쟁사 칸은 v17 근거가 있는 것만 ○·×로 쓰고, 나머지는 「— 미확인」이다. △를 미확인 뜻으로 쓰지 않는다.
- BidBox 기술 스택(제품 저장소 의존성 기준): FastAPI, SQLAlchemy, MySQL(pymysql), Parquet, LightGBM, CatBoost, ChromaDB, React·Vite, Docker. Polars·XGBoost·SBERT·JWT·WebSocket·LangChain·LangGraph는 BidBox 의존성에 없고 교육 과정 프로젝트에서 쓴 것이다.
- 노션의 옛 BIDBOX 수치(R2 0.63, MAE 1.87, 401,461건)와 「공공조달 관련 자료」의 출처 없는 통계(208.6조 원 등)는 계획서에 쓰지 않는다.
- 블라인드: 성명, 교육기관명, 팀원 이름, 학교명은 쓰지 않는다.
- 로컬 전용(공개 원격에 올리지 않음, `.git/info/exclude`에 `04_참고자료/_추출/`): 예시·v17·v18 텍스트 추출본, 분석 보고서 두 개, `노션_대표자역량_원자료.md`. 노션 원자료에는 성명·팀원 이름이 있어 올리지 않는다. 예시 docx 두 개(`04_참고자료/2026년 *.docx`)는 사용자 파일이라 커밋하지 않았다.
