## 바꾼 범위

장 코드(`(async () => {` 안, 표지~마무리)와 `problemCard`는 한 줄도 고치지 않았다. `K`의 hex와 키 이름, `THEME`도 그대로다.

### 1. 표면 함수 (`box`, `plate`, `chip`)

| 함수 | 항목 | 이전 | 이후 |
|---|---|---|---|
| `box` | 기본 모서리 | 0.14인치 | 0.05인치 (호출자가 `radius`를 넘기면 그 값) |
| `box` | 그림자 | `o.shadow`가 참이면 outer 12%·blur 8·offset 2 | 없음 (옵션 자체를 받지 않음) |
| `box` | 경계선 | 1pt (그대로) | 1pt |
| `plate` | 기본 모서리 | 0.18인치 | 0.05인치 |
| `plate` | 그림자 | 기본 켜짐 | 없음 |
| `chip` | 모서리 | 0.16인치 고정 | 0.05인치 (호출자가 `radius`를 넘기면 그 값) |
| `chip` | 경계선 두께 | 기본 1.5pt | 기본 1pt (호출자가 `lw`를 넘기면 그 값) |
| `chip` | 그림자 | 없음 | 없음 |

- 호출자가 `radius`(0.08·0.12·0.16·0.18)나 `lw`(1.5)를 넘긴 곳은 그 값을 유지한다. 그래서 2장 문제 카드(0.18)와 3·4·6·7·8·9장의 0.12 카드는 모서리가 그대로다. 장 워커가 나중에 좌표와 함께 덮어쓴다.
- 산출물 슬라이드 XML에 `shadow` 요소는 0개다. 호출부의 `shadow: true`는 남아 있지만 `box`가 더 이상 그림자를 그리지 않는다.
- `plate`·`setBg`·`bgImage`·`lightBgImage`는 10장 빌드에서 호출되지 않는다. 그래도 지시대로 세 함수의 불투명도를 함께 낮췄다.

### 2. 바탕 무늬 불투명도 (`washImage`, `lightBgImage`, `bgImage`)

10장 빌드는 `bg()`가 `washImage`만 쓴다. 종류(flow·docs·net·rings)와 시드 차이는 그대로 두었다.

|---|---|---|---|
| `washImage` docs | 종이 채움 / 테두리 / 줄 | 0.55 / 0.55 / 0.40 | 0.42 / 0.40 / 0.28 |
| `washImage` net | 선 / 강조 점 테두리 / 점 | 0.42 / 0.18 / 0.88·0.55 | 0.30 / 0.13 / 0.66·0.40 |
| `washImage` rings | 동심원 / 원 위 점 | 0.55−0.045k (최소 0.16) / 0.85 | 0.40−0.033k (최소 0.12) / 0.62 |
| `washImage` flow | 곡선 / 점 / 모이는 점 | 0.22+0.16r / 0.32+0.28r / 0.16·0.72 | 0.15+0.11r / 0.22+0.20r / 0.12·0.55 |
| `lightBgImage` docs | 종이 채움 / 테두리 / 줄 | 0.75 / 0.38 / 0.28 | 0.60 / 0.28 / 0.20 |

장 가장자리에서 반으로 잘리던 부분은 띠 안쪽으로 당겼다.

- `lightBgImage` docs: 회전한 종이의 x를 `PW−200`으로, y 시작 폭을 80→60으로 줄여 오른쪽·위 끝에서 잘리지 않게 했다.
- `bgImage` net·flow의 점은 이미 안쪽 40px·장 안쪽 좌표라 그대로 두었다. `washImage`의 net 점·flow 모이는 점도 이미 안쪽이다.
- rings는 중심을 장 밖(모서리)에 두는 구성 자체가 방향이므로 중심은 옮기지 않았다. 띠 마스크 안에서만 보이고, 불투명도를 낮춰 가장자리에서 끊기는 느낌을 줄였다.

### 3. 슬라이드 마스터 LIGHT/DARK 장식 색

- 눈썹(`eyebrow`) 색을 `dark ? K.onDarkMute : K.mute` 하나로 고정했다. 이전에는 QUIET이 아닐 때 어두운 장이 `K.skyOnDark`, 밝은 장이 `K.blue`였다. 기본값(QUIET 켜짐)에서는 결과가 같고, QUIET·FLAT을 끈 비교 빌드에서만 장식이 더 절제된다.
- 제목 32pt, 눈썹 자리(y 0.50, x M, 폭 CW), 꼬리말 로고 y 7.03은 그대로다. 배경색(`K.page`·`K.navy`)과 쪽 번호 색도 그대로다.
