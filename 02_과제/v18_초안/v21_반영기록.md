## 2. 서식 파이프라인 (AGENTS.md 2절 4단계)

lxml 파이썬(`/private/tmp/claude-501/…/scratchpad/venv/bin/python`)으로 압축 푼 폴더에서 실행했다. 순서와 출력은 아래와 같다.

```text
== fix_docx ==
{'rFonts': 1185, 'lang': 59, 'exact→atLeast': 0, '음수자간': 0, '장평': 0, 'pgSz': 5, 'compat': 0, 'fontTable 제거': 0}

본문 폭 9638 dxa {'표': 22, '셀': 530, '그림': 0}

== apply_style (--step 0) ==
문단 분류 — 장 제목 2, 표 제목 22, 소제목 15, 굵은 소제목 4, 주석 16, 그림 캡션 2, 본문 41, 그림 문단 10
표 칸 532, 음영 정규화 97개, 자간 -3, 위아래 여백 1417 글자 크기 — 장 제목 13pt, 표 제목 11pt, 소제목 11pt, 본문 10pt, 표·주석·캡션 9pt, --step 0
```

- 쓴 `--step`: **0** (축소 단계 없이 12쪽 이하로 들어왔다. `--step 1·2·3`은 쓰지 않았다)
- `compat` 0건: v20에서 이미 compatibilityMode 15였다.
- `exact→atLeast`·`음수자간`·`장평` 0건: v20에서 이미 정리되어 있었다.
- 표 칸 532 = 본문 표 530칸 + 머리말/꼬리말 표 칸 2개(v20과 같은 값).
- 음영 정규화 97개: 기존 D8D8D8·D5D5D5를 1-1절 값(D9D9D9·F2F2F2)으로 맞춘 결과다.
- `scripts/docx/*`는 고치지 않았다.
